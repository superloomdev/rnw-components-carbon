## What we ship

The registry is the union of `@carbon/react` (web) and `@carbon/react-native`, plus sanctioned non-Carbon exceptions (substrate primitives, collapsed variants, unexported indicators, and infrastructure providers).

Total: 243 built, 0 excluded.

## What Carbon has that we deliberately do not

Someone porting Carbon code needs to look up a missing component and find what replaced it, not conclude the library is incomplete.

| Carbon component | Status | Replacement / Reason |
|---|---|---|
| `Fluid*` variants | Collapsed | `FluidForm` provider with a `fluid` prop |
| `ButtonPrimary`, `ButtonLink` | Collapsed | `Button kind="primary" \| "ghost"` |
| `Card` | Collapsed | `Tile` covers the container use case |
| `Badge` | Collapsed | `Tag` and `BadgeIndicator` (both shipped) |
| `Separator` | Collapsed | Contextual dividers: `MenuItemDivider`, `SideNavDivider`, `SwitcherDivider` |
| `Divider` | Collapsed | Same as Separator |
| `DateRangePicker` | Collapsed | `DatePicker datePickerType="range"` |
| `SliderInput` | Collapsed | `Slider hideTextInput={false}` |
| `GridItem` | Collapsed | `Column span={n}` |
| `Fieldset`, `Legend` | Collapsed | Internal parts of `FormGroup` |
| `ToggleGroup` | Collapsed | `ContentSwitcher` is the segmented control |
| `ScrollGradient` | Deleted | Not in either Carbon package |
| `PaginationBar` | Collapsed | `Pagination` |
| `NumberInputComposite` | Collapsed | `NumberInput` molecule |
| `LayerMolecule` | Collapsed | `provider.Layer` |
| 24 `Skeleton*` variants | Collapsed | One `Skeleton` atom with shape props |
